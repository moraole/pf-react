# Erick Mora Olmedo Portfolio

A minimalist, single-page portfolio website built with React.

## Features
- Day/night theme toggle with animated star background
- Project case studies with slide-up panel
- Responsive design
- Subtle star animations with 4-pointed star shapes

## Tech Stack
- React
- TailwindCSS
- Canvas API

## Development
```bash
cd frontend
yarn install
yarn start
```

## Build
```bash
yarn build
```

## Deployment
Configured for Netlify deployment. See `netlify.toml` for configuration.
